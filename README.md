# Android Lab

Interactive lessons for Kotlin and Android: each one has an animated demo, a one-line rule to remember, practice challenges, and a quiz that comes back on a spaced-review schedule.

Plain HTML, CSS and JavaScript. No build step. Open `index.html` or serve the folder.

## Add a topic

1. Copy the shape of `tracks/kotlin.js` into `tracks/<name>.js` and call `Lab.addTrack({...})`.
2. Add `<script src="tracks/<name>.js"></script>` to `index.html`.

Search, the glossary, level filters and review pick it up automatically.

## Check

```
node check.js
```
